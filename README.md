# Springboot API Project

This is a Spring Boot based API project for handling cart management, user authentication, product management, and more. It includes integration with external services like Google OAuth2 and Facebook OAuth2 for user login. This project is designed for e-commerce functionality.

## Features

- User authentication with JWT.
- Google OAuth2 login integration.
- Facebook OAuth2 login integration.
- Cart management: Add, update, and remove products from the cart.
- Product and product variant management.
- File upload support for product images.
- SQL Server integration.

## Technologies Used

- **Spring Boot** for backend development.
- **Spring Data JPA** for database interaction.
- **SQL Server** for database storage.
- **JWT** for user authentication.
- **Google OAuth2 & Facebook OAuth2** for third-party login.
- **Lombok** for reducing boilerplate code.
- **GitHub Actions** for CI/CD.
